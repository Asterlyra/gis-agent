HOW THE AGENT WORKS

模型组织分析，GIS 计算空间结果

一个 Agent，由任务合同、模型决策、计划执行器、GIS 工具与检查器共同构成。当前使用 DeepSeek Flash；没有训练新模型，也没有多个角色 Agent 互相聊天。

输入如何进入系统？

  1. 用户选择真实区域、任务类型并填写距离。
  2. FastAPI 校验参数，启动独立 GIS 工作进程。
  3. 程序加载数据，形成输入画像和统一任务合同。
  4. 模型接收合同与工具定义；不读取任意文件，不获得参考答案。

实际输入示例

{
  "task_id": "jianghan-proximity",
  "distance_m": 500,
  "group": "C", "mode": "live",
  "prompt": "统计江汉区公交站500米内学校"
}

计划如何运行与修复？

  1. 计划校验拒绝未知工具、无效引用和依赖环。
  2. 执行器将 $near 解析为运行产生的 layer_N。
  3. 工具返回图层句柄、几何类型、数量与字段；程序保存几何快照和来源。
  4. 失败时停止依赖步骤；模型提交修订计划。
  5. 未变化且依赖未变的步骤保留，其余重新计算。

相同预算：最多 30 次模型请求、55 次 GIS 工具、2 次计划修订、600 秒。独立最终核验与运行检查分开。

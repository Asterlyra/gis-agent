# 设施邻近筛选与分区计数

读取图层说明和 task.schema，使用真正的业务 ID，不猜字段。以任务指定的米制分析 CRS 统一参与测量的图层。使用 within_distance 按真实几何距离筛选；缓冲多边形为圆的近似，若采用 buffer＋select 应考虑阈值附近误差。多个站点不能导致学校重复计数，按业务 ID 去重。学校归属分区时使用边界确定规则；本次数据没有边界学校。按分区统计后左连接到全部分区，填零。用 finalize 输出选中学校和统计分区。

规则知识：距离/面积算法的有效单位必须匹配任务；多图层操作使用兼容的 CRS；字段存在且类型正确；最终学校集合按业务 ID 唯一；全部分区应恰好出现一次；计数为非负整数。合法空结果需要输出零值分区，不能报错。对于工具已正确支持的坐标转换不必重复操作。
